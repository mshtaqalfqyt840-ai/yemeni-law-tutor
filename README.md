# ⚖️ المعلّم الذكي – القانون المدني اليمني
**(Yemeni Civil Law AI Tutor - RAG Based System)**

مشروع ذكاء اصطناعي تفاعلي متقدم مصمم لشرح وتوضيح مواد **القانون المدني اليمني**. يعتمد النظام على معمارية التوليد المعزز بالاسترجاع (RAG) ليضمن تقديم إجابات قانونية موثوقة ومقاومة للهلوسة 100%، حيث يلتزم المحرك باستخلاص إجاباته حصرياً من النصوص القانونية المعتمدة المستخرجة من مذكرات وملفات الـ PDF.

---

## 🛠 المعمارية التقنية والتقنيات المستخدمة
تم تصميم هذا النظام وفق أحدث الأنماط الهندسية وأكثرها كفاءة:
- **LangChain (LCEL):** استخدام لغة التعبير السلسة (LangChain Expression Language) لربط دوال الاسترجاع (`create_retrieval_chain`) وتوليد المستندات (`create_stuff_documents_chain`) بأداء عالٍ.
- **ChromaDB:** قاعدة البيانات المتجهة المحلية والمفتوحة المصدر لتخزين مقاطع النصوص القانونية (Embeddings) واسترجاعها بسرعة فائقة.
- **Google Gemini API & Local Embeddings:** الاعتماد على نموذج `gemini-flash-latest` كعقل مدبر للإجابة بـ `Temperature=0.1` لمنع التأليف، ونموذج التضمين المحلي المجاني والمجرد `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` لبناء المتجهات بدون قيود حصة استدعاء.
- **Streamlit:** إطار العمل السريع لبناء واجهة مستخدم تفاعلية، معرّبة بالكامل (RTL) وتتضمن إدارة الجلسات (`session_state`).
- **PyPDFLoader:** أداة معالجة متقدمة لمسح ملفات الـ PDF واستخراج النصوص منها بكفاءة عالية للحفاظ على التنسيق العربي.

## ✨ المميزات الهندسية الاستثنائية

### 1. تقطيع ذكي حسب المادة القانونية (Smart Legal Splitter)
بدلاً من التقطيع العشوائي للنصوص بناءً على عدد الكلمات، تم تطوير خوارزمية ذكية مخصصة (`split_law_by_article`) باستخدام التعابير النمطية (Regex) للتعرف على صيغ المواد القانونية مثل `مادة (1):`. تضمن هذه الخوارزمية ألا يتم تقسيم أي مادة قانونية في المنتصف، مع حفظ اسم الباب القانوني واسم الملف الأصلي كبيانات وصفية (Metadata) لتعزيز دقة الاسترجاع.

### 2. مدير مفاتيح ديناميكي (Smart API Key Manager)
لتجنب انقطاع الخدمة بسبب قيود معدل الاستخدام (Rate Limits)، تم تصميم كلاس متقدم لإدارة مفاتيح الـ API يوفر:
- **التناوب (Rotation):** التبديل بين عدة مفاتيح لتوزيع الحمل.
- **الاسترداد التلقائي (Fallback):** في حال حظر أحد المفاتيح أثناء توليد الإجابة، يتم استبعاد المفتاح التالف والانتقال فوراً للمفتاح البديل دون أن يشعر المستخدم بأي توقف، وفي أسوأ الظروف يقوم النظام بتصفير قائمة الحظر (Reset) لتفادي انهيار التطبيق.

### 3. معالجة ذكية للبيانات الضخمة
يقوم النظام بعمل مسح تلقائي لمجلد `data/` بأكمله، ليقرأ عشرات الملفات من نوع PDF دفعة واحدة، ويستخرج آلاف النصوص ويقوم بفلترتها هندسياً للعثور على المواد القانونية الصريحة قبل تحويلها إلى متجهات.

### 4. شفافية المصادر (Source Transparency)
أسفل كل إجابة يقدمها "المعلّم الذكي"، يُعرض قسم قابل للطي يعرض (اسم الملف الأصلي المستخرج منه، واسم الباب، ورقم المادة، ونصها الحرفي)، لإثبات موثوقية كل إجابة مقدمة.

## 🚀 دليل التشغيل السريع

### 1. إعداد البيئة الافتراضية
تأكد من تثبيت Python، ثم قم بفتح الطرفية (Terminal) في مسار المشروع ونفذ الآتي:
```bash
# إنشاء بيئة افتراضية
python -m venv venv

# تفعيل البيئة (في نظام ويندوز)
.\venv\Scripts\activate
# لتفعيل البيئة (في ماك/لينكس)
# source venv/bin/activate
```

### 2. تثبيت الحزم المطلوبة
```bash
pip install -r requirements.txt
```

### 3. إعداد المفاتيح وبناء قاعدة البيانات
1. قم بفتح ملف `config/api_keys.json` وأضف مفاتيح Google API الخاصة بك الصالحة للاستخدام.
2. قم بوضع أي مذكرات قانونية (PDF) داخل مجلد `data/`.
3. قم بتشغيل سكربت التضمين لبناء قاعدة البيانات محلياً (يُنفذ مرة واحدة فقط أو عند إضافة ملفات جديدة):
```bash
python utils/ingestion.py
```

### 4. إطلاق واجهة التطبيق
بمجرد نجاح الخطوة السابقة، ابدأ بتشغيل واجهة الويب التفاعلية عبر الأمر:
```bash
streamlit run app.py
```
سيظهر لك رابط محلي (غالباً `http://localhost:8501`)، قم بفتحه في متصفحك لبدء المحادثة مع المعلّم الذكي!
