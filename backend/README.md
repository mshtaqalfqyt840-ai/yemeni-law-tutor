# 🏛️ المعلّم الذكي - خادم الكواليس (FastAPI Backend)

هذا المجلد يحتوي على خادم الـ API المطور باستخدام **FastAPI** لخدمة واجهة **React** وتطبيقات الويب والجوال، بحيث يعمل بالتوازي مع تطبيق **Streamlit** الحالي دون أي تأثير عليه.

## 🌟 الميزات والتصميم المعماري

- **سرعة فائقة**: استجابة لحظية للاستعلامات باستخدام `FastAPI` و `Pydantic v2`.
- **بث حي عبر SSE (Server-Sent Events)**: إرسال الردود كلمة بكلمة (`/api/chat/stream`) مع إرسال المصادر القانونية أولاً لتعرضها الواجهة فوراً.
- **تكامل تام مع قاعدة البيانات**: يتصل مباشرة بقاعدة البيانات المتجهة (`chroma_db_v2`) ويستخدم نماذج التضمين المحلية ومفتاح `Google Gemini API` من نفس ملفات الإعدادات الحالية.
- **CORS مفعّل**: يدعم الاتصال بأي واجهة (React Vite / Next.js / Flutter) على المنفذ `5173` أو `3000` أو عبر الإنترنت.

---

## 🚀 تشغيل خادم FastAPI محلياً

لتشغيل خادم الكواليس على المنفذ `8000`:

```powershell
# من داخل المجلد الرئيسي للمشروع
.\venv\Scripts\uvicorn.exe backend.main:app --host 0.0.0.0 --port 8000 --reload
```

بعد التشغيل يمكنك زيارة:
- **الواجهة التفاعلية لتوثيق الـ API (Swagger UI):**  
  [http://localhost:8000/docs](http://localhost:8000/docs)
- **فحص صحة الخادم:**  
  [http://localhost:8000/](http://localhost:8000/)
- **إحصائيات النظام:**  
  [http://localhost:8000/api/stats](http://localhost:8000/api/stats)
- **بطاقات الاقتراحات القانونية:**  
  [http://localhost:8000/api/suggestions](http://localhost:8000/api/suggestions)

---

## 📡 أهم مسارات الـ API (Endpoints)

| المسار | الطريقة | الوصف |
| :--- | :--- | :--- |
| `/` | `GET` | فحص عمل الخادم وحالته |
| `/api/stats` | `GET` | إحصائيات قاعدة البيانات (2,920 مادة، دقة الإسناد، سرعة الاسترجاع) |
| `/api/suggestions` | `GET` | قائمة بطاقات الاقتراحات مع أيقونات SVG وتصنيفات قانونية |
| `/api/chat` | `POST` | استشارة قانونية (رد كامل دفعة واحدة بصيغة JSON) |
| `/api/chat/stream` | `POST` | استشارة قانونية ببث حي للرد (SSE Streaming) |
